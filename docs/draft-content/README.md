# Draft content sheets

Fill in `flights.csv`, `hotels.csv` and `visas.csv` (Excel or Google Sheets), one listing per row. Only the facts you can stand behind: leave a cell blank rather than guess. Everything is created as a draft; publishing is done in the admin.

Required: Name and Summary on every sheet; From and To (flights); Country and Visa (visas). Hotels need a hotel name, or one of our own properties (say which).

Allowed values:

| Column | Values |
|---|---|
| Trip | One way, Return, Multi-city |
| Cabin | Economy, Premium economy, Business, First |
| Board | Room only, Bed and breakfast, Half board, Full board, All inclusive |
| Prices | whole or decimal US dollars, e.g. 180 or 25.50 |

Each listing also needs a main photo, added in the admin before it can be published.
